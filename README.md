This entry publishes one 1024×1024 news image for 25 November 2026. The Node 22 program in `main.ts` uses only the standard library: it creates the output directory when that directory is missing, then copies `entry.png` to `entry.png` inside `MAKEFUN_OUTPUT_DIR`, falling back to `/output` when the variable is unset. It does not open a network connection.

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
